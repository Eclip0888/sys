How to read the AI's explanations

The AI predicts whether a student will PASS or FAIL from six study habits. With each answer it shows one of three explanations. Here is the same student explained three ways.

Example student: {{ sample }}. The AI says {{ pred.label }} ({{ '%.0f'|format(pred.prob_pass*100) }}% chance of passing).

1. SHAP

Each bar shows how much one factor moved the chance of passing for this student, starting from the average of all students. Green bars push toward passing, red bars toward failing. The longest bar had the biggest effect. Adding all the bars to the average gives this student's chance. A long bar shows what the model relied on, not what causes passing in real life.

{{ x.shap(views['SHAP']) }}

2. LIME

LIME tries many small variations of this student's inputs and fits a simple model around them. Each row is a condition (a range of values) with a weight: positive supports PASS, negative supports FAIL. The explanation is only valid near this student, not for everyone.

{{ x.lime(views['LIME']) }}

3. Counterfactual

A counterfactual answers "what is the smallest change that would make the AI say the opposite?" It only changes factors the student can still change (the previous grade stays fixed). It shows what changes the model's prediction, not a guarantee in real life.

{{ x.cf(views['CF']) }}
